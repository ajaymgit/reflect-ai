# Patent Readiness Checklist (India Focus)

Use this before filing to keep ReflectAI/Equoria claims defensible and implementation-backed.

## 1) Novelty Evidence

- [ ] Keep a dated log of algorithm milestones (EGRS gates, EVPE lifecycle, atomic claim checks).
- [ ] Capture before/after examples showing reduced unsupported claims.
- [ ] Document what is technically different vs generic journaling chatbots.

## 2) Inventive Step Support

- [ ] Show why combining evidence gates + hypothesis state + temporal checks is non-obvious.
- [ ] Include reproducible experiments where weak evidence is correctly blocked.
- [ ] Record measurable technical effect (fewer invalid claims, higher consistency, traceability).

## 3) Enablement

- [ ] Freeze architecture diagrams and data flow for filing package.
- [ ] Keep API schemas (`insight`, `evidence`, `confidence`, `reasoning`) versioned.
- [ ] Archive prompt/policy versions used for the claimed behavior.

## 4) Claim Drafting Inputs

- [ ] One independent system claim (end-to-end evidence-gated reflective pipeline).
- [ ] One independent method claim (context assembly -> generation -> claim verification -> audit logging).
- [ ] Dependent claims on health reliability filter, retraction handling, and claim lock behavior.

## 5) Filing Hygiene

- [ ] Run prior-art search updates before final filing draft.
- [ ] Ensure consistent terminology across abstract, detailed description, and claims.
- [ ] Keep source snapshots and test reports as supporting annexures.
